# RxJS Architecture Explorer

**ФИО:** Мосин Денис Юрьевич  
**Библиотека:** RxJS  
**Версия:** 7.8.2  
**Репозиторий библиотеки:** https://github.com/ReactiveX/rxjs/tree/7.8.2

## Цель проекта

Продемонстрировать работу Observable, цепочек операторов, подписок, teardown и обработки ошибок в RxJS через интерактивные примеры.

## Используемые технологии

React, TypeScript, Vite, RxJS 7.8.2, CSS, Vitest, ESLint, Prettier.

## Запуск проекта

Требуются Node.js 22 и npm.

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173.

Все проверки: `npm run check`.
